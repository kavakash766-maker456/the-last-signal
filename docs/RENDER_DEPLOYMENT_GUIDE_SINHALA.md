# සේවාදායකය (Colyseus Server) නොමිලේ Render හි ස්ථාපනය කිරීමේ සරල මඟපෙන්වීම

මෙම ක්‍රීඩාවේ බහුක්‍රීඩක (Multiplayer) පද්ධතිය ක්‍රියාත්මක වන්නේ **Colyseus** සහ **WebSockets** මඟිනි. Vercel වැනි සේවාවන් සාමාන්‍ය වෙබ් අඩවි සඳහා විශිෂ්ට වුවද, නිරන්තරයෙන් සම්බන්ධ වී සිටින (Persistent Real-time) සේවාදායකයක් Vercel හි ධාවනය කළ නොහැක. 

එබැවින් අප Colyseus සේවාදායකය සඳහා **Render.com** හි නොමිලේ ලබාදෙන (Free Tier) සේවාව තෝරාගෙන ඇත.

---

## 1. Render.com තෝරාගත්තේ ඇයි?

1. **නොමිලේ භාවිතා කළ හැක (Free Tier)**: මාසයකට පැය 750 ක් නොමිලේ හිමිවේ (එක් සේවාදායකයක් මුළු මාසය පුරාම ධාවනය කිරීමට ප්‍රමාණවත්ය).
2. **WebSockets සහයෝගය**: ක්‍රීඩකයන් 4 දෙනෙකුට එකවර සම්බන්ධ වී එකිනෙකාගේ චලනයන් සහ ක්‍රියාකාරකම් සජීවීව දැකීමට අවශ්‍ය WebSocket පහසුකම පවතී.
3. **නොමිලේ SSL (WSS)**: ඔබගේ වෙබ් අඩවිය Vercel හි `https://` ලෙස ක්‍රියාත්මක වන විට, බ්‍රව්සරයෙන් සේවාදායකයට සම්බන්ධ වීමට ආරක්ෂිත `wss://` ලිපිනයක් අනිවාර්ය වේ. Render විසින් මෙය නොමිලේම සපයයි.
4. **ක්‍රෙඩිට් කාඩ්පත් අවශ්‍ය නොවේ**: ආරම්භකයෙකුට කිසිදු ගෙවීමකින් තොරව පහසුවෙන්ම සකසාගත හැක.

> **සැලකිය යුතුයි (Cold Start)**: Render හි Free සේවාදායකයක් විනාඩි 15 ක් කිසිවෙකු නොසිටියහොත් තාවකාලිකව "Sleep" වේ. නව ක්‍රීඩකයෙකු සම්බන්ධ වන විට එය නැවත අවදි වීමට තත්පර 40-50 ක් පමණ ගතවේ. අපගේ ක්‍රීඩා අතුරුමුහුණත (UI) මෙම කාලය තුළ පැහැදිලි සිංහල පණිවිඩයක් පෙන්වමින් ක්‍රීඩකයා රඳවා තබාගැනීමට සකසා ඇත.

## 2. Render හි සේවාදායකය සැකසීමට පියවරෙන් පියවර (Step-by-Step)

### පියවර 1: GitHub වෙත Code එක Push කිරීම
1. ඔබගේ GitHub ගිණුමට මෙම ව්‍යාපෘතිය (`the-last-signal`) අලුත් Repository එකක් ලෙස Upload (Push) කරන්න.

### පියවර 2: Render.com හි ලියාපදිංචි වීම
1. [https://render.com](https://render.com) වෙත පිවිසෙන්න.
2. ඔබගේ GitHub ගිණුම හරහා පහසුවෙන්ම Sign Up වන්න.

### පියවර 3: නව Web Service එකක් සෑදීම
1. Render Dashboard එකේ ඉහළ දකුණු කෙළවරේ ඇති **"New +"** බොත්තම ඔබා **"Web Service"** තෝරන්න.
2. ඔබගේ GitHub ගිණුම සම්බන්ධ කර, ඔබ විසින් සාදන ලද `the-last-signal` repository එක තෝරන්න (Connect).
3. පහත විස්තර ඒ ආකාරයෙන්ම ඇතුළත් කරන්න:
   - **Name**: `the-last-signal-server` (හෝ ඔබ කැමති නමක්)
   - **Region**: Singapore හෝ Oregon (ආසියාවට ආසන්න එකක් තෝරාගැනීම සුදුසුය)
   - **Root Directory**: `server`
   - **Environment / Runtime**: `Node`
   - **Build Command**: `npm install && npm run build`
   - **Start Command**: `npm run start`
   - **Instance Type**: **Free** (නොමිලේ)
4. පිටුවේ පහළ ඇති **"Create Web Service"** බොත්තම ඔබන්න.

විනාඩි 2-3 කින් සේවාදායකය සාර්ථකව Build වී ධාවනය වේ. එහිදී ඔබට Render වෙතින් URL එකක් ලැබෙනු ඇත (උදාහරණයක් ලෙස: `the-last-signal-server.onrender.com`).

## 3. Frontend එක Vercel වෙත දැමීම සහ සේවාදායකය සම්බන්ධ කිරීම

1. [https://vercel.com](https://vercel.com) වෙත ගොස් ඔබගේ GitHub ගිණුම හරහා `the-last-signal` සම්බන්ධ කරන්න.
2. **Root Directory** එක ලෙස `client` තෝරන්න.
3. **Environment Variables** යටතේ පහත අගය එකතු කරන්න:
   - **Key**: `VITE_SERVER_URL`
   - **Value**: `wss://the-last-signal-server.onrender.com` (Render වෙතින් ඔබට ලැබුණු නම `wss://` සමඟ ඇතුළත් කරන්න).
4. **Deploy** බොත්තම ඔබන්න.

දැන් ලෝකයේ ඕනෑම තැනක සිටින මිතුරන් 4 දෙනෙකුට Android දුරකථනයකින් හෝ පරිගණකයකින් බ්‍රව්සරය හරහා Room Code එකක් මඟින් එකතු වී ක්‍රීඩා කළ හැක!
